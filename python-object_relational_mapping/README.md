# Python - Object-relational mapping

MySQLdb and SQLAlchemy scripts for working with MySQL databases.

Tasks:
- **0-select_states.py** - Lists all states
- **1-filter_states.py** - Lists states starting with N
- **2-my_filter_states.py** - Lists states matching user input (vulnerable)
- **3-my_safe_filter_states.py** - SQL injection safe filter
- **4-cities_by_state.py** - Lists all cities with state names
- **5-filter_cities.py** - Lists cities of a given state
- **model_state.py** - State ORM model
- **7-model_state_fetch_all.py** - Lists all State objects
- **8-model_state_fetch_first.py** - Prints first State
- **9-model_state_filter_a.py** - Lists states containing 'a'
- **10-model_state_my_get.py** - Gets state by name
- **11-model_state_insert.py** - Adds Louisiana state
- **12-model_state_update_id_2.py** - Updates state id=2
- **13-model_state_delete_a.py** - Deletes states with 'a'
- **model_city.py** - City ORM model
- **14-model_city_fetch_by_state.py** - Lists all cities with state names
