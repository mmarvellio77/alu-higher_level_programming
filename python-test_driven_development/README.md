# Test-driven Development

Python test-driven development (TDD) tasks covering:

- **0-add_integer.py** - Adds two integers, casting floats to ints
- **2-matrix_divided.py** - Divides all elements of a matrix by a divisor
- **3-say_my_name.py** - Prints a formatted full name
- **4-print_square.py** - Prints a square using `#`
- **5-text_indentation.py** - Prints text with 2 new lines after `.`, `?`, and `:`
- **6-max_integer.py** - Finds the max integer in a list
